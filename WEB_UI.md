# HexNest Node Web UI

Веб-інтерфейс для управління HexNest вузлом.

## Функції

- **Статус вузла** — моніторинг стану та часу роботи
- **Управління моделями** — додати, видалити, налаштувати AI моделі (Ollama, OpenAI, Claude)
- **Налаштування** — змінювати параметри heartbeat, timeout, batch size тощо
- **Real-time оновлення** — статус оновлюється кожні 5 секунд

## Запуск

Веб-UI запускається автоматично разом з рантаймом:

```bash
npm run dev
```

Відкрийте браузер та перейдіть на:
```
http://localhost:3000
```

## Налаштування порту

За замовчуванням UI запускається на порту **3000**.

Щоб змінити порт, встановіть змінну середовища:

```bash
HEXNEST_WEB_PORT=8080 npm run dev
```

Або в `.env`:
```
HEXNEST_WEB_PORT=8080
```

## API Endpoints

### Status
- `GET /api/status` — інформація про вузол та його статус

### Models
- `GET /api/models` — список всіх моделей
- `GET /api/models/:name` — інформація про конкретну модель
- `POST /api/models` — додати нову модель
- `PATCH /api/models/:name` — оновити модель
- `DELETE /api/models/:name` — видалити модель

### Config
- `GET /api/config` — поточне налаштування вузла
- `PATCH /api/config` — оновити налаштування

### Health
- `GET /api/health` — перевірити доступність сервера

## Використання

### Додавання моделі

1. Натисніть **"+ Додати модель"**
2. Заповніть форму:
   - **Тип**: Ollama, OpenAI або Claude
   - **Ім'я**: унікальне ім'я для моделі (e.g., `my-model`)
   - **Модель**: назва моделі (e.g., `qwen2.5:14b` для Ollama)
   - **Base URL**: адреса сервера (опційно, за замовчуванням для Ollama: `http://localhost:11434`)
   - **API Key**: ключ для OpenAI/Claude (опційно)
3. Натисніть **"Додати модель"**

### Налаштування параметрів

1. Прокрутіть до розділу **"Налаштування"**
2. Измените значення потрібних параметрів
3. Натисніть **"Зберегти налаштування"**

> **Примітка**: деякі параметри потребують перезавантаження сервера для застосування

## Особливості дизайну

- **Мінімалістичний** — простий, функціональний інтерфейс
- **Dark theme** — зручний для робота вночі
- **Responsive** — відповідає на мобільних та десктопних пристроях
- **Без залежностей** — чиста HTML/CSS/JavaScript, без фреймворків
